# Contributing to Svelte AutoForms

Thank you for your interest in contributing to Svelte AutoForms! We welcome contributions from the community.

## Development Setup

1. Clone the repository:
```bash
git clone https://github.com/TechplexEngineer/svelte-autoforms.git
cd svelte-autoforms
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Make your changes and test them in the demo page at http://localhost:5173

## Building

To build the library:
```bash
npm run build
```

To check for TypeScript errors:
```bash
npm run check
```

## Project Structure

- `/src/lib/components/` - Svelte components (AutoForm, field components)
- `/src/lib/themes/` - Theme configurations
- `/src/lib/utils/` - Utility functions (schema parser)
- `/src/lib/types/` - TypeScript type definitions
- `/src/routes/` - Demo application

## Coding Guidelines

- Use TypeScript for all new code
- Follow the existing code style
- Add JSDoc comments for public APIs
- Include examples in the demo page for new features
- Ensure all builds pass before submitting

## Submitting Changes

1. Fork the repository
2. Create a new branch for your feature or bugfix
3. Make your changes
4. Test your changes thoroughly
5. Submit a pull request with a clear description of your changes

## Reporting Issues

If you find a bug or have a feature request, please open an issue on GitHub with:
- A clear description of the problem or feature
- Steps to reproduce (for bugs)
- Expected behavior
- Actual behavior
- Your environment (OS, Node version, etc.)

## Code of Conduct

Please be respectful and constructive in all interactions. We're here to build great software together!
